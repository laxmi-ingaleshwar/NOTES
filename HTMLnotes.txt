SOFTWARE is a set of instructios/ programs that tells computer/device how
to perform specific task.

TYPES OF SOFTWARE.
1. SYSTEM SOFTWARE-
software that manages & supports a computer's hardware & core function.
ex- Operating Systems like windows, linux / MacOS

2. APPLICATION SOFTWARE
software that runs upon system software & designed for end-users to perform
specific task.
ex- Microsoft-word, Google Chrome, Spotify


TYPES OF APPLICATION SOFTWARE
1.DESKTOP SOFTWARE
*Internet connection is not mandatory.
*Installation is mandatory.
ex- Paint Appication, MS-Excel


2. WEB SOFTWARE
* It requires internet connection to use.
* Installation is not Mandotory.
ex- Instagram, Chat-GPT


HTML--- Hyper Text Markup Language.
HTML is used to create a structure of a webpage.
To create HTML file we supposed to use .html extension.
HTML is not case sensitive in Nature, either we can go with uppercase/ lowercase
but it is always recommended to go with lower case.

HISTORY
HTML is invented by TIM BERNERS LEE in 1991.
version 1.0 was released for public in 1993.
current version is html5.

THREE-TIER-ARCHITECTURE
1.PRESENTATION-TIER
client side- HTML, CSS, Javascript

2. LOGIC TIER
server side- Node.js , Java, python, PHP

3.DATA TIER
Database- SQL, Mongo Db

TAGS
Tags are predefined keywords which are enclosed in Angular braces <>
1. Paired Tag--> A tag which is required of both opening tag and closing tag.
ex. <html> </html>

2. Unpaired Tag--> A tag which is not required both opening and closing tag.
ex. <br>, <hr>, <!DOCTYPE HTML>

FORMATING TAGS
Used to format the text based content for better look and feel.
1. Physical tag
Tag which are focuses only on Physical appearance of text.
ex-<b>=bold, <i>=Italic, <u>=Underline

2.Logical tag
tag are used to give some logical/semantic value to the text.
these tag conveys the purpose & meaning 
ex-strong, code, em

ELEMENTS
Elements is  A Combination of opening tag & closing tag along with content.
Void element-> element which does not have any closing tag.

TYPES OF ELEMENTS
1.Block level element
Always start on a new line, occupies the full available width of it's parent container.
ex= All the heading tag, div tag

2.Inline Level Elements
It doesn't start on a new line, occupies only the content width.
ex= <b>, <i>, <span> => we cannot provide height and width for these element

Semantic Tags
The tag itself defines Meaning& purpose of the content to the browser.
ex= <header>, <article>, <main>, <section>

Non-semantic Tags
The tag itself doesn't defines meaning & Purpose of the content to the browser.
ex=<div>, <span>

HTML LIST=> used to specify list of informations/items.

TYPES
1.ORDERED LIST(ol) 
The list which can follow the order is known ordered list.
all the list items are marked with numbers by default, so it's known as "Number list"
we can change the order with the help of type attribute.
<ol>
    <li> HTML </li>
    <li> CSS </li>
    <li> JS </li>
</ol>


2.UNORDERED LIST(ul)
A list which cannot follow any order is called as unordered list.
Default type is "disc" also called as "Bullet list"
<ul>
    <li> COFFEE </li>
    <li> TEA </li>
    <li> MILK </li>
</ul>


3. DESCRIPTION LIST(dl)
This is rarely used list, used to list out items with description <dl>
<dt>=Description Term, <dd>=Description Data
<dl>
    <dt> CSS </dt>
    <dd> Cascending Style Sheet </dd>
    <dt> HTML </dt>
    <dd> Hyper text markup language </dd>
</dl>


4.Nested list
The list which is present inside another list is called Nested list.
It may be the combination of ordered, unordered, & description list.

<ol>
    <li> Front end skills </li>
    <ul type="disc">
        <li> HTML </li>
        <li> CSS </li>
        <li> JS </li>
    </ul>
    <li> Backend Skills </li>
    <ul type="square"> 
        <li> JAVA </li> 
        <li> PYTHON </li>
    </ul>
</ol>



ATTRIBUTES
Attributes are special keywords which are provided in the opening tag of the element, 
it will provide additional information about element.
1.id=> uniquely identify an element, one element should have one id only
2.class=> used to group similar elements, one element can have multiple classes.
3.style=> used to give inline CSS
4.title=> used to provide the tooltip. which is extra information to the user, once he hovers the cursor over the element.
5.type=> specifies what kind of input field it is.

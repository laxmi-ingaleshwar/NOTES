JAVASCRIPT

*Javascript is a high level programming language,
*which is used to create interactive webpages.
*it is a language we can use browser side(frontend) as well server side(backside).

Frontend=> React.js, Angular.js, Next.js
Backend=> Node.js, Express.js

we use JS because it makes web pages interactive.

With JS:
* Can create dynamic content like (pop-ups, forms & Animations.)
* It let's users Interact (click,scroll,type,play music.)
* It works in the browser without needing extra software,
basically, JS makes website alive instead ofjust looking like a book.


Without JS:
* A website is just static. 
It only shows text & images but doesn't respond when we click buttons / type something.

CHARACTERESTICS:
1. client-side scripting language
Runs inside the browser.
No need for server to process every action.

2. Dynamic Typed
No need to define variable type.
JS automatically detects the type at runtime.

3. Weakly Typed
Allows Operations between different data types.
can cause unexpected behaviour.

4. Interpreted language
executes code line by line.
can cause delays if one task takes too long.


JAVASCRIPT CAN RUN IN TWO MAIN ENVIRONMENTS.
1.Browser-
* Runs inside the browser like Chrome/Edge etc.
* No need to setup - Just browsers console.

2.Node.js-
* runs JS outside the browser.
* Require installing node.js


WAYS TO ADD JAVASCRIPT.
1. INTERNAL JS
by using <script> tag, at the end of the <body> tag
2. EXTERNAL JS
by using .js file


VARIABLES-
Variables is like container that stores data.
It holds values that can be used & changed in a program.

Basic
var box; // declaration
box="Toys" // Initialization
Here, box is a variable & inside that variable we stored toys as values

types
1.Var
2.let
3.Const

DATATYPES.

3.Boolean

5.Undefined

2.Non-Primitive Data Types.

OPERATORS.
Operators are symbols/functions, that performs a specific operation on 
one/more operands/pre-defined symbols used to perform some specific task.

TYPES.
1. Unary Operators=> Works on single Operand.
2. Arithmetic Operators=> Perform Basic Mathematical Operations.
3. Assignmet Operators=> Assign values to Variables.
4. Comparison Operators=> Gives result in true/false.
5. Bitwise Operators=> Perform bit-level operations.


DECISION MAKING STATEMENTS.
Helps the program decide what to do based on the conditions.

1. if-statement 
2. if-else statement
3. else-if ladder

LOOPING STATEMENTS
way to repeat a block of code multiple times based on a condition, Helps in doing repetitive tasks.

1. For loop=> used when we know how many times we want the code to run.
2. While loop=> runs as long as condition is true. 
3. Do-while loop=> similar to while loop but it runs atleast once.

FUNCTION 
Function is a block of code written to perform a specific task.
it is executed when it is called / invoked.
function helps to avoid repetation of code & make it reusable.

function functionName(parameters){
    //function body
    // code to be executed
}

ex=
function print(){
    console.log('good morning')
}
print()

Function Call statement=> Part of the program where function is called/executed.
To call a function , we simply use it's function name & followed by paranthesis().

PARAMETER=> is a variable defined in a functions definition.
ARGUMENT=> is the actual value that is passed to a function when it is called.

TYPES OF FUNCTIONS 
1.Named Function
2.Anonymous Function 
3.Arrow Function
